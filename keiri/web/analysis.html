経理ラボ『バランスシート』 設計のための調査

ヒットしているスマホRPGは、何をしているか

2025年の国内売上上位と、物語・キャラクター・育成で評価されているRPGを調べ、『バランスシート』に取り入れることと、取り入れないことを決めました。

結論：今の『バランスシート』に足りないのは、次の5つ
  1. 最初の1分で遊ばせる。読ませてから遊ばせる順番を逆にする。
  2. 物語は無料で読めて、戦闘は流れを止めない。物語の戦闘は編成固定にする。
  3. 何度も遊べる短い「育成ラン」を中心の遊びにする。学習の反復はここに入れる。
  4. キャラクターと距離が縮まる仕組み（絆ランクと、チャットでのやりとり）。
  5. 1日2回、短時間でも開く理由（時間で回復する無料の報酬、連続ログイン）。

市場：2025年の国内売上上位

集計元によって順位は少し違いますが、上位はほぼ共通しています。RPG・キャラクター育成系では『Fate/Grand Order』『ウマ娘』『崩壊：スターレイル』が年間上位に入りました。上半期の収益・ダウンロード数のトップは『ポケポケ』です。

ヒット作に共通するパターン

1. 物語は無料、戦闘で流れを止めない

『ブルーアーカイブ』は、メインストーリーをスタミナを使わずに読めるようにし、物語の中の戦闘は編成を固定して流れが途切れないようにしています。人気に火がついたのは、物語と演出に力を入れた章からだと開発側も語っています。

→ 取り入れる：ストーリーは無料。物語の中のバトルは、仲間を固定して短く。

2. 絆が深まると、その人の物語が読める

『ブルーアーカイブ』の「モモトーク」は、ゲーム内のチャットでキャラクターとやりとりし、絆ランクが上がると個別の絆ストーリーが解放される仕組みです。メインに出番の少ないキャラクターも掘り下げられます。

→ 取り入れる：カサネは IT企業なので、社内チャットがそのまま舞台装置になる。社長の朝9時2分の無茶振りもチャットで届く。絆ランクで、志乃の試験の話や墨谷の過去の断片が読める。

3. 何度も遊べる「育成ラン」

『ウマ娘』は、ランダムなイベントと選択で毎回結果が変わる育成を何度も繰り返す作りです（1回30分〜1時間超）。選択肢の効果を見えるようにする改善もしています。『学園アイドルマスター』は、育成にデッキ構築ローグライクの要素を入れたことで、繰り返し遊べる点が評価されています。

→ 取り入れる（短く）：「月次決算ラン」。1回5分で、1か月を4週＋締め日で進める。毎週3枚の行動カード（仕訳処理・照合・研修・休む）から1枚を選び、ランダムな事件（天城案件、請求書が届かない、など）に対応して、最後に「締め日」のボスに挑む。行動の中身が問題なので、遊ぶほど経理が身につく。

4. 行動順が見えるターン制

『崩壊：スターレイル』は、ターン制で行動順が見えることで、反射神経より事前の計画やチームの組み合わせを考える楽しさを出しています。

→ 取り入れる：敵の「あと何ターンで反撃してくるか」を常に表示する。仲間の必殺技をいつ使うかの判断を生む。

5. 1日2回開く理由と、短い1回

『ポケポケ』は12時間ごとに無料パックを開けられ、対戦も短いので、少しの空き時間でも開く習慣が作られています。一方で、開封の演出を飛ばせないことは不満として指摘されています。Duolingo は連続記録とそれを守るアイテムで習慣を作っています。

→ 取り入れる：12時間ごとに無料の「辞令封筒」（スカウト1回分）。連続ログインと「有給休暇届」（連続記録を守る）。どの演出も必ず飛ばせるようにする。

6. 最初は「やって覚える」

オンボーディングについての解説では、読ませるより実際に操作させて覚えさせること、最初に機能を詰め込みすぎないことが繰り返し挙げられています。日本のスマホゲームでは、最初の数分で無料のガチャ（チュートリアルガチャ）を引かせるのが一般的です。

→ 取り入れる：冒頭30秒でミニバトル。5分以内に無料の「辞令封筒10通」で仲間を手に入れる。機能はホーム画面で1つずつ解放する。

7. ガチャは「表示」と「上限」を守る

条件をそろえると景品がもらえる「コンプガチャ」は、景品表示法の「カード合わせ」に当たり禁止です。確率の表示は、業界団体（JOGA）のガイドラインで定められています。

→ 取り入れる：提供割合を必ず表示し、天井（一定回数で確定）を付ける。コンプ要素は作らない。課金はデモのまま、請求は発生させない。

取り入れないこと

オートバトル・放置

多くのRPGは周回をオートで済ませられますが、この企画は「答えること」が攻撃であり学習そのものです。オートにすると学習が消えるので入れません。代わりに1回を短くして、作業感を減らします。

長い育成（30分以上）

通勤や昼休みに遊ぶ社会人が対象なので、1回5分で終わる長さに抑えます。

スタミナでストーリーを止めること

物語で続きが気になったところで止められるのは、離脱の原因になります。スタミナ（気力）は月次決算ランにだけ使います。

冒頭5分の設計

  1. 0:00起動。いきなり「初めての月次決算の夜、締めまであと3時間」。志乃に急かされながら、3問のミニバトル（30秒）。答えるたびに攻撃の演出。
  2. 0:45勝つとタイトル『バランスシート』。名前を入れる（あとで変更できる）。
  3. 1:00「——1年前」。父の回想は3行だけ。入社式で天城社長の最初の無茶振り。最初の選択。
  4. 2:30経理部で墨谷・志乃と出会う。「1円合わないのは、1円の問題じゃない」。第1話の終わりに引き。
  5. 3:00入社祝いとして「辞令封筒10通」（無料スカウト）。★4以上を1通確定。封筒を開ける演出（飛ばせる）。
  6. 4:00ホーム画面。好きな仲間が立っていて、社内チャットに天城社長から最初のメッセージが届く。「つづきから」と「月次決算ラン」が光っている。
