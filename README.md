# 短期トレード・ラボ（クラウド版）

スマホ・PCのブラウザから使える、短期売買の分析・検証・記録アプリです（Streamlit）。

- 起動ファイル：`app.py`
- 必要なライブラリ：`requirements.txt`（Streamlit Cloud が自動でインストール）
- 保存先：Secrets に Google スプレッドシートを設定すると、記録が消えずに残ります。設定しない場合は一時保存（アプリ再起動で消える）。
- パスワード：Secrets に `app_password` を設定すると、開くときにパスワードが必要になります。

設定の書き方は `secrets_example.toml` を参照（このファイルは公開しないこと）。

⚠️ 本アプリは条件に合うチャートを機械的に探す分析ツールで、投資助言ではありません。

# 経理ラボ（経理の学習アプリ）

`keiri/` フォルダにある、経理の仕事を学ぶための別アプリです（Streamlit）。

- 起動：`streamlit run keiri/app.py`
- Streamlit Cloud で公開する場合は、新しいアプリを作り Main file path に `keiri/app.py` を指定
- 機能
  - **キャリア**：新入社員 → 担当者 → 主任 → 係長 → 課長 → 経理部長へ昇進していくストーリー。期ズレ・振込詐欺・源泉徴収・交際費・税務調査・社内不正・資金繰り・押し込み販売・粉飾の誘惑など27場面の実務判断
  - **証憑チェック**：請求書・領収書・経費精算の不備（インボイス要件、計算ミス、詐欺の兆候など）を見抜く
  - **入金消込パズル**：手数料差引・まとめ入金・名義違い・過入金を含む入金を請求と突き合わせる
  - 講座（簿記の基本9章＋実務2章、理解チェック付き）／仕訳ドリル（37問）／勘定科目クイズ／用語クイズ／帳簿づくり（仕訳→元帳→試算表→P/L・B/S）／経理カレンダー／科目辞典
- 登場する会社名・人名はすべて架空です
- 学習記録はブラウザを開いている間だけ保持。ホームの「学習記録の保存・読み込み」から JSON で保存できます
