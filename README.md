# 短期トレード・ラボ（クラウド版）

スマホ・PCのブラウザから使える、短期売買の分析・検証・記録アプリです（Streamlit）。

- 起動ファイル：`app.py`
- 必要なライブラリ：`requirements.txt`（Streamlit Cloud が自動でインストール）
- 保存先：Secrets に Google スプレッドシートを設定すると、記録が消えずに残ります。設定しない場合は一時保存（アプリ再起動で消える）。
- パスワード：Secrets に `app_password` を設定すると、開くときにパスワードが必要になります。

設定の書き方は `secrets_example.toml` を参照（このファイルは公開しないこと）。

⚠️ 本アプリは条件に合うチャートを機械的に探す分析ツールで、投資助言ではありません。

# 経理ラボ（経理の学習アプリ）

`keiri/` フォルダにある、経理の仕事をゲーム感覚で学ぶスマホ向けアプリです。

- 起動：`streamlit run keiri/app.py`（Streamlit Cloud の Main file path も `keiri/app.py`）
- 本体は `keiri/web/index.html`（HTML/JS の1ファイル）。問題データは `keiri/content.py`・`keiri/content_jitsumu.py` にあり、編集したら `python keiri/web/build.py` で再生成する
- 機能
  - **学ぶ**：7ユニット・18レッスンの学習マップ。仕訳はタップで科目カードを借方・貸方に振り分け、証憑は不備を見抜く。正解で判子、コンボ、紙吹雪
  - **キャリア**：新入社員 → 経理部長。チャット形式で27の事件に判断を下し、信頼度を集めて昇進（辞令の演出つき）
  - **ゲーム**：45秒のスワイプ仕分け、デイリークエスト
  - **続けたくなる仕掛け**：連続日数（ストリーク）、XP・レベル、1日の目標、バッジ、マスコット「チョーボ」の着せ替え
  - **課金要素（デモ）**：ハート制、Pro プラン（ハート無制限・係長〜部長編・苦手復習・総まとめテスト・コイン2倍・限定着せ替え）、コインショップ、コインパック。デモのため実際の請求は発生せず、支払い情報も入力しない
- 進み具合は端末のブラウザに保存されます
- 旧版（表形式の学習ツール）は `streamlit run keiri/classic.py`
- 登場する会社名・人名はすべて架空です
