# 短期トレード・ラボ（クラウド版）

スマホ・PCのブラウザから使える、短期売買の分析・検証・記録アプリです（Streamlit）。

- 起動ファイル：`app.py`
- 必要なライブラリ：`requirements.txt`（Streamlit Cloud が自動でインストール）
- 保存先：Secrets に Google スプレッドシートを設定すると、記録が消えずに残ります。設定しない場合は一時保存（アプリ再起動で消える）。
- パスワード：Secrets に `app_password` を設定すると、開くときにパスワードが必要になります。

設定の書き方は `secrets_example.toml` を参照（このファイルは公開しないこと）。

⚠️ 本アプリは条件に合うチャートを機械的に探す分析ツールで、投資助言ではありません。

# 経理ラボ

`keiri/` フォルダにある2つのアプリです。`streamlit run keiri/app.py` で起動し、画面上部で切り替えます（Streamlit Cloud の Main file path も `keiri/app.py`）。どちらも `python keiri/web/build.py` で生成します。

## 経理ドリル（勉強用）

- 本体：`keiri/web/drill.html`（`drill.src.html` と問題データから生成）
- 目的を「簿記3級・簿記2級・経理の実務・すべて」から選ぶ。1回5・10・20問、約270問（追加問題は `keiri/content_drill.py`）
- まちがえた問題は翌日、正解するたびに2日後・4日後・8日後…と間をあけて出す（3回続けて正解で「覚えた」）
- 記録は端末のブラウザに保存。連続日数、まちがえた問題だけの復習、分野別の練習

## バランスシート（ゲーム）

新入社員からCFOまで、仕事と人生の選択を重ねる恋愛ADV。ヒロインは朱野志乃・霧島玲・新堂結・渚の4人。各章の休日イベントで好感度を上げ、第14話「連結」でプロポーズの相手を選ぶと、4章以降の家庭パートとエンディングが相手ごとに変わる（設計：`keiri/web/heroines.html`）。

- 本体：`keiri/web/balance.html`（`python keiri/web/build.py` で `balance.src.html`・問題データ・立ち絵から生成）
- 遊び
  - **ストーリー**（無料）：1話3〜5分。1章「期首」〜7章「決算」の全35話＋終章（人生のバランスシートと選択で5種類のエンディング）。物語の中のバトルは仲間固定
  - **バトル**：問題に答えると攻撃。制限時間・速答クリティカル・コンボ・仲間の必殺技（カットイン）・敵の反撃カウント
  - **月次決算ラン**（気力10）：4週＋締め日を1回5分で回す育成ラン。行動カード、ランダムな事件、締め日のボス
  - **スカウト**：辞令封筒で仲間カードを集める。提供割合・天井を表示。課金はデモで請求なし
  - **社内チャット**：キャラクターとのやりとりで絆が上がる
  - ログインボーナス、デイリーミッション、12時間ごとの無料スカウト、結果画面で間違えた問題を見直し
- 設定資料：`keiri/web/heroines.html`（ヒロインとルートの設計案、アニメ調の画像指示文）、`keiri/web/cast.html`（登場人物）、`keiri/web/prompts.html`（画像生成プロンプト）、`keiri/web/analysis.html`（ヒットRPGの分析）
- 立ち絵：`keiri/web/img/人物_表情.webp`。元画像は `python keiri/web/tools/prep_portrait.py 元画像 出力.webp` で背景を抜いて作る（`pip install "rembg[cpu]"`）
- 旧版：`keiri/web/index.html`（学習アプリ版）、`streamlit run keiri/classic.py`（表形式の学習ツール）
- 登場する人物・会社はすべて架空です

# ミラペア（試作品）

`mirapair/` フォルダにある、恋人との相性と「ふたりの未来」を毎日のぞくアプリの試作品です。`mirapair/index.html` をブラウザで開くか、`streamlit run mirapair/app.py` で起動します。

- リサーチと設計：`mirapair/research.html`
- 区分：高校生／大学生・専門学生／新社会人／社会人／30代（16歳から）。高校生は年収・子ども・写真の機能なし、課金は月1,500円まで
- ホーム：今日のふたり予報、1日1問（ふたりとも答えると相手の答えが見える・相手の答え予想）、連続日数とおやすみ券、記念日カウント
- 診断：星と数の相性、価値観の一致（30問をふたりが別々に）、鑑定ショップ
- 未来：子どもの身長（幅つき）、ふたりの家計（世帯年収・教育費）、暮らしの予報、写真で見る未来（画面だけ。AIでの画像づくりは未対応）
- 課金：ふたりプラス（学生 月380円／社会人 月680円）と単品の鑑定。デモで請求なし
- 通知：種類ごとのオン・オフと時刻の表示、テスト通知。決まった時刻に届く通知とふたりのスマホをつなぐ機能は、サーバーが必要なので未対応
- データは端末のブラウザにだけ保存。年収・教育費は公的統計をもとにした概算
